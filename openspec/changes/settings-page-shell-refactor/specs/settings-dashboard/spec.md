## ADDED Requirements

### Requirement: 设置页分组卡片结构

设置页 MUST 将相关设置项组织为多个带标题的卡片区块，至少包含「常规设置」「输出设置」「缓存设置」置于主列，「更新设置」「隐私设置」「关于工具箱」置于次列或与设计稿一致的栅格布局；每个卡片 MUST 使用统一的外边距、圆角与背景色以与首页卡片风格协调。

#### 场景：用户打开设置页

- **WHEN** 用户导航至设置页且页面渲染完成
- **THEN** 用户 MUST 能辨认至少两个独立设置卡片及其标题
- **THEN** 卡片内控件 MUST 不溢出卡片边界（在应用默认窗口尺寸下）

### Requirement: 设置行统一信息结构

除特殊区块外，每个具体设置项 MUST 采用「左侧标题与可选说明、右侧控件」的行布局；标题 MUST 清晰表达该项含义，说明文案 SHOULD 在需要时解释副作用或持久化范围。

#### 场景：用户阅读语言设置项

- **WHEN** 用户查看界面语言设置行
- **THEN** 该行 MUST 在左侧展示标题与说明（若规格文案要求）
- **THEN** 语言选择控件 MUST 出现在该行右侧并与 `settings.store` 中语言值绑定

### Requirement: 主题模式分段控件

应用 MUST 提供主题模式选择控件，包含「跟随系统」「浅色」「深色」三种互斥选项，且同一时刻 MUST 仅有一种模式处于选中态；选中项 MUST 与 `settings.store` 或等价全局主题状态同步。

#### 场景：用户切换到深色模式

- **WHEN** 用户在设置页选择「深色」主题分段项
- **THEN** 应用界面 MUST 应用深色主题（或按现有主题系统等价行为）
- **THEN** 持久化层 MUST 在刷新后仍保持深色选择（若产品要求持久化）

### Requirement: 路径类目录行与操作按钮

对于默认输出目录与缓存目录等路径类设置，界面 MUST 展示当前路径文本，并提供「更改」与「打开」操作入口；「打开」在具备本地路径访问能力时 MUST 打开系统文件管理器定位到该目录，不具备能力时 MUST 降级为可理解的提示而非静默失败。

#### 场景：用户点击打开输出目录

- **WHEN** 用户已配置有效输出目录且底层能力可用
- **THEN** 用户点击「打开」后系统文件管理器 MUST 在该目录打开或展示等价反馈

### Requirement: 危险操作视觉与确认

清除本地数据等破坏性操作 MUST 使用危险主色按钮样式，且 MUST 在执行前弹出确认对话框，用户取消时 MUST 不产生数据删除。

#### 场景：用户取消清除数据

- **WHEN** 用户点击「清除本地数据」并在确认框中选择取消
- **THEN** 应用 MUST 不删除本地持久化数据
- **THEN** 用户 MUST 仍停留在设置页且状态与点击前一致

### Requirement: 关于区块信息

关于卡片 MUST 展示应用名称、版本号、简短描述，以及「检查更新」「用户协议」「隐私政策」等链接或按钮；版本号 MUST 与构建或配置中的应用版本一致（单一数据源）。

#### 场景：用户查看关于信息

- **WHEN** 用户滚动至关于卡片
- **THEN** 用户 MUST 能看到应用名称与版本号
- **THEN** 点击「检查更新」MUST 触发与产品定义一致的更新检查流程或占位提示（若流程尚未接入）
