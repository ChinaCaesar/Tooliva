## ADDED Requirements

### Requirement: 应用壳层提供主内容区域

应用壳层 MUST 提供单一主内容区域，用于承载各路由页面组件，且主内容区域 MUST 在视觉与结构上独立于侧栏与顶栏，以便滚动行为主要作用于主内容而不影响侧栏与顶栏固定策略（除非产品明确要求整体滚动）。

#### 场景：设置页挂载于壳层主内容区

- **WHEN** 用户处于设置路由且应用使用壳层布局
- **THEN** 设置分组卡片与标题 MUST 出现在壳层主内容区域内
- **THEN** 侧栏与顶栏 MUST 仍保持可见且与首页使用同一套组件或等价结构

### Requirement: 侧栏主导航与当前项高亮

侧栏 MUST 展示与设计稿一致的一级导航项（含返回首页、首页、全部工具、分类入口、更多工具、会员中心、历史记录、设置等，具体项以产品配置为准），且 MUST 根据当前激活路由高亮对应项。

#### 场景：在设置页时设置项为高亮态

- **WHEN** 当前路由为设置页
- **THEN** 侧栏中「设置」对应项 MUST 呈现激活样式
- **THEN** 其他非当前路由项 MUST 不呈现与「设置」相同的激活样式

### Requirement: 顶栏全局搜索与快捷提示

顶栏 MUST 包含居中搜索入口，展示占位文案与键盘快捷提示（在 Windows 与 macOS 上文案或组合键 MAY 按平台区分），且搜索选择结果 MUST 能够导航至对应工具或页面（行为与首页顶栏一致或可配置为同一数据源）。

#### 场景：用户在设置页使用搜索

- **WHEN** 用户在设置页激活搜索并选择某一工具结果
- **THEN** 应用 MUST 导航至该工具对应路由或等价目标

### Requirement: 顶栏右侧会员与窗口控制

顶栏 MUST 在右侧区域提供会员开通入口（若业务启用）、设置入口（若与侧栏设置不重复则按产品设计二选一或并存），以及桌面端窗口最小化、最大化与关闭控制（在 Tauri 环境下由现有窗口 API 驱动）。

#### 场景：用户从设置页点击窗口最小化

- **WHEN** 用户在设置页点击顶栏最小化按钮
- **THEN** 应用窗口 MUST 进入最小化状态且不应丢失当前路由状态

### Requirement: 底栏品牌文案

壳层 MUST 在页面底部展示与设计稿一致的品牌或情感化文案区域，且文案 MUST 走 i18n，不得硬编码为单一语言。

#### 场景：语言切换后底栏更新

- **WHEN** 用户将界面语言从中文切换为英文
- **THEN** 底栏展示文案 MUST 更新为当前语言对应翻译
