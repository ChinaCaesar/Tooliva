## Context

- 当前仓库首页由 `HomePage.vue` 编排：`HomeTopBar`、`CoreToolGrid`（三列双行网格）、`RecentUsageList`、`SideInfoPanel`（统计与快捷操作）、`HomeFooterBar`；数据由 `useHomePageData` 与 `home.config` 等拼装。
- 桌面端默认窗口为 Tauri 配置中的 **1200×720**（`src-tauri/tauri.conf.json`），与参考稿「一屏仪表盘」目标接近，可作为「推荐视口」基准。
- 本次变更以参考图为视觉与信息层级目标，以 proposal 中 `home-dashboard` 能力为需求边界。

## Goals / Non-Goals

**Goals:**

- 在推荐视口下，首页**不出现页面级纵向滚动条**（视口指 WebView 内可见区域；若外层壳体存在系统标题栏，由应用窗口高度配置保证内容区可用高度与 720 设计一致或文档化偏差）。
- 主区与侧栏结构与参考稿一致：**问候与主推区、横向大卡、最近使用、价值卖点横条、侧栏三块卡片、顶栏与页脚信息层级**。
- 组件边界清晰：`HomePage.vue` 仅编排与子组件事件；各区块独立 `.vue`；配置与视图模型与 UI 解耦，便于迭代。
- 小于推荐视口时，有**明确降级策略**（断点栈式或区域内滚动），避免布局崩坏。

**Non-Goals:**

- 不实现真实会员支付、订阅后端或账号体系（侧栏会员区可为占位与路由预留）。
- 不强制实现参考图中的全部美术资源（3D 插图可用静态图或简化装饰）；不引入新的重型动画框架。
- 不要求在任意极端尺寸（例如高度极小）下仍无滚动——该情形归入降级路径。

## Decisions

1. **布局骨架：单列 flex + 主行 flex:1**
   - **做法**：整页 `flex-direction: column`；顶栏与页脚固定高度或 `flex-shrink:0`；中间 `flex:1; min-height:0` 容纳「主列 + 侧栏」行，避免子元素把页面撑出视口却无法收缩。
   - **备选**：纯 `grid` 模板行 `auto 1fr auto`。选用 flex 因与现有 `home-page__content` 心智一致、调试成本低。

2. **推荐视口与验收基准**
   - **做法**：以 **宽度 ≥1200px 且高度 ≥720px**（与默认窗口一致）为「一屏无页面级滚动」的验收基准；内容区内部使用 `min-height:0` 与合理 `gap`，避免无意溢出。
   - **备选**：提高基准至 1280×800——暂不采用，以免与当前 Tauri 默认窗口不一致。

3. **侧栏内容替换策略**
   - **做法**：以新组件实现「安全说明 / 会员权益 / 更新日志」三卡；数据以配置数组 + i18n 键为主，更新日志可先静态配置，结构与 `SideInfoPanel` 解耦，必要时删除或收缩旧「统计/快捷操作」模块以免重复占位。
   - **备选**：在 `SideInfoPanel` 内堆叠三种 section——否决，单文件易再次膨胀，违背组件化目标。

4. **主推工具区形态**
   - **做法**：由横向「大卡」列表组件承载（含「更多/即将推出」占位卡），工具元数据仍来自统一配置，与搜索候选、路由映射共用单一数据源，避免 `HomePage.vue` 内重复分支。
   - **备选**：保留 `CoreToolGrid` 仅改样式——否决，与参考稿行列结构差异大，维护成本高。

5. **国际化**
   - **做法**：新增或调整的文案一律走 `vue-i18n` 键值；组件接收已翻译字符串或由子组件基于 key 调用 `t()`，与现有一致。

6. **会员按钮**
   - **做法**：首版为**占位**：可点击弹出「敬请期待」或静默，需在规格中写明行为，避免用户误以为已开通支付。

## Risks / Trade-offs

- **[风险] 文案变长或新增语言导致溢出** → [缓解] 主标题与卡片描述限制最大行数（`line-clamp`）或略调字号阶梯；在规格场景中覆盖「长文案不破坏布局」。
- **[风险] 断点栈式后纵向高度不足** → [缓解] 明确「小于基准视口」时允许页面级或主区滚动，并在 tasks 中列为可测项。
- **[风险] 与现有 `CoreToolGrid` / `SideInfoPanel` 路由或测试耦合** → [缓解] 删除或替换组件时同步更新引用与快照测试（若有）。

## Migration Plan

1. 在功能分支上按 `tasks.md` 顺序替换布局与组件；每步保持 `pnpm` 构建与本地 `tauri dev` 可启动。
2. 合并前检查首页路由与顶栏搜索跳转仍指向既有工具页。
3. 回滚：恢复变更前的 `HomePage.vue` 与 `home/components` 相关文件（Git 回退即可），无数据库迁移。

## Open Questions

- 会员占位点击后的具体交互（弹窗文案、是否记录「不再提示」）是否由产品补充。（当前实现：顶栏与侧栏会员按钮均导航至 `ROUTE_PATHS.membership` 占位页。）
- 更新日志是否在首版接远程或仍为本地静态列表。（当前实现：静态 `HOME_CHANGELOG_MOCK`；「查看全部」弹出说明对话框。）
- 应用中文品牌名「工具箱」与产品名 `Desktop Toolbox` 在顶栏的展示策略是否统一为 i18n 可切换。
- **搜索快捷键（已决议）**：`Ctrl+K`（Windows / Linux）与 `⌘+K`（macOS）聚焦顶栏搜索输入框；界面展示文案分别使用 `pages.home.topBar.searchShortcut` 与 `pages.home.topBar.searchShortcutMac`，与行为一致。
