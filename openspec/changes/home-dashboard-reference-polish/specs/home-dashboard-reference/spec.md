## ADDED Requirements

### Requirement: 首页不得展示高频使用工具

系统必须在首页移除「高频使用工具」区块及其入口；不得再请求或展示基于 `topTools` 的前端视图模型；相关 Vue 属性、事件与 composable 返回值必须删除或收敛至无引用状态。

#### Scenario: 用户浏览首页

- **WHEN** 用户打开首页并完成渲染
- **THEN** 页面上不存在「高频使用工具」标题或列表，且控制台无未定义属性或缺失 prop 告警

### Requirement: i18n 键必须全部可解析

凡首页通过 `t(...)` 或配置 `*Key` 引用的文案键，必须在当前语言包（至少 `zh-CN` 与 `en-US`）中存在相同路径的翻译；界面不得出现以 `pages.home.` 开头的原始键名字符串。

#### Scenario: 用户切换为简体中文

- **WHEN** 语言为简体中文且首页渲染完成
- **THEN** 侧栏三张卡片标题、「查看全部」、会员按钮等均以中文展示，不出现 `pages.home.sections.sidebar` 等键名文本

#### Scenario: 用户切换为英文

- **WHEN** 语言为英文且首页渲染完成
- **THEN** 上述位置均以英文展示且无键名泄漏

### Requirement: 最近使用区版式须符合参考稿单区列表

最近使用区域必须采用单一内容区：包含区块标题、可选「查看全部」操作，以及按时间或占位排序的条目列表；条目必须展示工具图标、名称、相对时间与文件名（或占位）；视觉密度（圆角、间距、字号）须以参考稿为基准实现，不得再使用双列分栏承载其他模块。

#### Scenario: 用户查看最近使用

- **WHEN** 首页存在最近使用数据或空态占位
- **THEN** 用户仅在同一视觉区域内看到条目列表，且布局与参考稿一致（无双列「高频」并列）

### Requirement: 主推工具卡视觉基线

主推工具卡片区必须满足：圆角、内外边距、标题与描述层级、图标占位尺寸及阴影与参考稿一致或在设计文档约定的误差范围内；卡片在默认窗口宽度下须保持可读且不重叠。

#### Scenario: 默认窗口下查看主推卡

- **WHEN** 视口宽度为 1200px 且显示首页主推工具卡
- **THEN** 卡片标题与描述字号、间距与参考稿目检一致，无异常换行裁切按钮文案
